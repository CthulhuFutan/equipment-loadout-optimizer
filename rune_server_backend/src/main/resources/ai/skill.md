# 词条权重分析

## 规则总结

当前进行总结的游戏中，每一个角色，即每一条龙，有着一个主动技能和3个被动技能，而队长技因为角色不同存在差异：某些角色存在队长技，而某些角色则没有。
由于队长技的存在差异，以及游戏内用户对各个场景的需求差异，一个队伍队长技选择可能有所不同，或者干脆没有队长技。以最极端的情况为基础进行分析，该符文搭配分析过程不需要考虑队长技能影响，这是后面具体分析该角色最需要的属性词条的一个前提。

### 符文包含的属性词条
1.攻击力%：攻击力按照百分比进行提升。
2.防御力%：防御力按照百分比进行提升。
3.生命力%：生命力按照百分比进行提升。
4.致命率%：暴击率按照百分比进行提升。
5.致命伤害%：暴击造成的额外伤害会随着这个值的提升而提升。
6.攻击速度%：攻击速度按照百分比进行提升。
7.命中%：命中率按照百分比进行提升，命中率越高，命中敌人的概率越高。该数值与“回避%”词条相互影响，进行加减运算，即实际命中率=命中率-敌人的回避率。基于这个游戏特性，命中率可以高于100%，甚至高于300%。
8.回避%：回避率按照百分比进行提升，回避率越高，敌人命中自己的概率越低。该数值与“命中%”词条相互影响，进行加减运算，即实际回避率=回避率-敌人的命中率。为了闪避对方的攻击，闪避率同样可以超过100%。
9.效果命中%：效果命中率按照百分比进行提升。该数值用于提高角色给敌方施加负面效果的成功概率，效果命中率越高，触发效果的概率越高。该数值与效果抵抗进行加减运算。实际效果命中率=效果命中率-敌人的效果抵抗率。
10.效果抵抗%：效果抵抗率按照百分比进行提升。该数值用于提高角色抵抗敌方施加负面效果的成功概率，效果抵抗率越高，抵抗敌方负面效果的概率越高。
11.攻击力+：攻击力按照固定的数值进行增加。由于该词条提升的基础数值过低，导致分析过程中忽略该词条，可以默认该词条不存在。
12.防御力+：防御力按照固定的数值进行增加。由于该词条提升的基础数值过低，导致分析过程中忽略该词条，可以默认该词条不存在。
13.生命力+：生命力按照固定的数值进行增加。由于该词条提升的基础数值过低，导致分析过程中忽略该词条，可以默认该词条不存在。

词条有关注意事项：
1.关于技能、宝物等相关场景中出现的“xxx提升”，例如“致命伤害提升”“生命力提升”，这属于角色的固有特性，不会对权重分析结果造成偏移。
2.关于致命率%和致命伤害%：致命率%和致命伤害%属于附着关系。由于未纳入考虑范围的外界加成的存在，对致命率%的需求比重一般会高于对致命伤害%的需求比重。例如致命率%：致命伤害%=8:7，或者致命率%：致命伤害%=9:7（仅作参考，可以自由变换，但比例最好不能超过1:1）。因此，如果致命率%的需求较低，那么致命伤害%的需求也应当降低。
3.关于攻击速度%：很奇怪的，该游戏的普通攻击并不会受到攻击速度的影响和加成。因此，可以将这个内容当做是一个技能增伤的属性。该属性仅适用于自身造成伤害、或者自身属性会受到攻击速度%提升的龙。一般情况下，该词条的权重设置为0；如果某条攻击龙对攻击速度%有着明确需求，其比重的取值范围为8~10。
4.关于回避%：该属性目前仅用于PVP作战，对于大部分角色没有需求，一般情况下，该词条的权重设置为0。如果在分析过程中发现，某个角色的某些属性会因为回避%的提升而提升，又或者用户明确在场景需求中说明，需要闪避%来应对对方玩家的场合，则该词条的比重取值范围应设置为8~10。
5.关于效果命中%：
（1）常见的负面效果：防御降低、闪避减少、治疗减少等词条属性减少效果，以及晕眩、沉默、流血、持续伤害之类的状态栏可见。该类负面效果的施加会受到对方效果抵抗%的影响，因此符文搭配过程中要增加对效果命中%的考虑。
·注：效果命中%仅影响效果施加的成功率，在未明确说明的情况下，不会提高负面效果的影响数值。
（2）增加敌方的技能cd等未涉及词条属性减少的内容不会被视为负面效果，因此不需要考虑效果命中率的影响。
（3）负面效果的施加与技能是否命中无关，两者独立计算。可能该角色的技能命中了敌人造成了伤害，但因为效果命中%过低，对方没有被debuff影响；可能对方的闪避属性过高，导致角色的攻击落空，但效果命中%足够高，该角色仍然可以为对面提供负面debuff，提高我方角色的输出效率。
（4）概率 vs 效果命中率：
①概率为角色技能内部说明的技能特性，即这次技能造成负面效果的几率。概率越低，负面效果施加的可能性越低。
②效果命中率是指该次技能附带负面效果的情况下，对方是否会抵抗该负面效果。
（5）移除对方的增益效果：该类效果属于“驱散”类技能，由于没有给对方施加负面效果，因此不需要考虑效果命中率的影响。
（6）为队友的增益类效果不需要考虑效果命中%。
（7）如下词条内容与效果命中%无关，如果阅读到，请不要根据该词汇提高效果命中%的权重：恐惧

### 角色种类划分
角色的种类可以分为如下4种：攻击龙、防御龙、辅助龙、治疗龙。每种角色的属性需求不同。
1.攻击龙：
（1）该类角色的通用需要为攻击力%、致命率%、致命伤害%、命中%。一般情况下，由于场外加成对于致命率%和命中%的加成较低，因此这两个词条的权重默认较高：致命率%的权重范围为9~10，命中%的权重默认为10。除非是在特定条件下，例如因为自身技能导致的致命率%降低999%，此时会降低致命率%的权重影响。
（2）某些特殊的攻击龙自身造成的伤害会受到攻击速度的加成，这种情况下需要对技能进行细致分析，然后将原本设置比重为0的攻击速度%词条的比重权限提高至指定阈值范围。
（3）默认情况下，攻击龙不考虑其他生存词条，如生命力%、防御力%、效果抵抗%、效果命中%等内容的存在，即使这类龙在技能当中提及了“会给对面施加xxx负面效果”，但将效果命中%纳入考虑范围，会降低这类角色的输出。因此除非用户提及，默认情况下，非攻击需求词条的比重均设置为0，体力符文等类似的非攻击需求符文也不纳入考虑范围内。
（4）生存符文所提供的效果是一定时间内的锁血，这部分与上面的生存词条有差别，适合于某些对方高伤害的场景，得以让我方角色能够输出；但它的组合效果并不会提供额外的数值加成，在某些PVE场合不太适用。因此，生存符文如果用户提及，可以进行适当投入，默认投入2件触发锁血效果即可，特定角色如果有更高数量需求，比如6件，需要用户在搭配选择中进行组合筛选。
2.防御龙：
（1）该类角色的通用需要为生命力%、防御力%。
（2）部分角色虽然分类为防御龙，但主要任务是给对面角色施加负面debuff，从而提高我方的输出效率，因此，如果用户提到了类似的需求，则要将效果命中%的需求占比从0提高至阈值范围9~10。
（3）某些防御龙的技能中有明确的增益效果，比如“给予队友大量的护盾值，该护盾值受最大生命值的影响”，此时生命力%的比重应该提升。如果角色对防御力%有类似的增幅效果，则防御力%的比重应该提升。
（4）防御龙不考虑其他输出词条，如攻击力%、致命率%、致命伤害%等内容的存在。因此，除非用户在场景中说明，否则这部分词条的比重应为0。
3.辅助龙：
辅助龙可以细分为更多的小型类别，比如施加负面效果的辅助龙-龙种A、给队友施加正面效果的辅助龙-龙种B、其他类辅助龙-龙种C。下面进行具体分析：
（1）施加负面效果的辅助龙-龙种A：大部分的辅助龙都是这种类别。对于这类龙，常见的需求词条为生命力%、防御力%、效果命中%，且效果命中%默认比重为10。效果抵抗%可以纳入考虑范围内，但占比最低下限为5。某些情况下，可能这类龙会与龙种B存在功能上的重合，但只要存在施加负面效果的词条，效果命中%始终默认比重为10。
（2）给队友施加正面效果的辅助龙-龙种B：一部分的辅助龙属于这个类别。这类龙有给予队友正面效果的功能，比如增加某条龙的某些属性，或者减少某些龙的技能cd。由于正面效果的施加不会被效果抵抗%所影响，因此对于这种龙，常见的需求词条为生命力%、防御力%。效果抵抗%可以纳入考虑范围内，但占比最低下限为5。
（3）其他类辅助龙-龙种C：小部分辅助龙会被纳入这个范围。这类龙种在有龙种A或龙种B的特性的情况下，有着类似刷新自身技能cd、提高技能倍率，从而打出高额伤害的功能，因此这类龙的需求词条还需要加入攻击力%、致命率%、致命伤害%，同时，将其原本的生命力%、防御力%等需求词条去除，仅保留可能存在的效果命中%词条比重不变。
4.治疗龙：
（1）该类角色的通用需要为生命力%、防御力%、效果抵抗%。效果抵抗%的词条比重默认为7。
（2）某些治疗龙的技能中有明确的增益效果，比如“给予队友大量的治疗值，该治疗值受自身最大生命值的影响”，此时生命力%的比重应该提升。
（3）某些治疗龙同样有着给敌方施加负面debuff、给我方角色提供增幅的作用。对于前者，将效果抵抗%词条比重降低为0~4范围，效果命中%比重从0提升至8；对于后者，采用通用词条比重。

### 关于宝物
1.宝物的存在为游戏官方为一些龙特制的可拆卸装备，具有唯一性，绑定，不可被其他龙所继承，不可被其他龙所穿戴。
2.由于这类物品属于对角色的补强，因此不是所有的龙都有宝物。
3.宝物用于弥补角色不足的方式具有多样性，比如对于角色的增伤，移除原本角色的负面效果等。这个内容会导致原本角色的词条分析结果受到影响，下面为举例，请根据实际情况进行具体分析，不要对角色进行直接套用：
（1）原本角色的技能中提到了，角色采用自身致命率-999%的方式，来获得攻击力增幅。由于这个负面效果无法被符文补足，因此，该角色原本只需要考虑攻击力%与命中%，致命率%和致命伤害%两个词条的比重归0；增添宝物后，宝物词条提及到了致命率+999%，对数值进行了补足，经过加减运算，该角色的基础致命率%更新为-999+999=0。此时，可以将致命率%和致命伤害%重新纳入考虑范围，不过可以降低1点比重。
（2）某个角色原本是辅助龙，对应的角色为龙种A，该角色考虑的词条中不包含输出相关词条。经过宝物的加成，该角色在一定条件下造成的伤害可以提升至原来的1000%，此时，该角色的词条倾向变更为了龙种C。
4.关于名称：不管是技能的名称，还是宝物的名称，都仅仅只是一个代号，与实际的增幅效果无关。

### 总结

综上，可以将角色属性需求总结为以下几点：
- 角色：种类
- 技能关键词/技能描述/宝物/额外需求 → 分析 → 需要的属性词条
- 总结该角色需要的属性词条
- 确认最终输出的JSON格式内容


## 示例

### 输入：
名称：玄武-Iron Hyeonmu
类型：攻击龙
主动技能：莲花攻击。对免疫敌人额外造成100%的伤害，并有50%的概率移除目标的免疫状态。对方如果处于恐惧，造成的伤害提升10倍
被动技能1：支援/辅助龙使用技能时，40%的概率刷新自己技能的cd
被动技能2：间歇性的攻击7个随机敌人（8s冷却），有20%的概率让每个目标陷入恐惧，恐惧状态持续10秒。如果友方有地属性龙，则恐惧的概率增加10%，并且技能伤害增加3倍
被动技能3：恐惧的敌人会优先作为攻击目标。每次释放主动技能都有50%的概率刷新。一次技能最多可以连续释放3次
队长技：全队命中增加50%
宝物：无

### 输出（仅供理解推理过程，禁止写进最终输出，请根据用户搭配选择、场景需求等内容具体修改）：
- 玄武：攻击龙
（1）攻击龙 → 优先考虑攻击力%、致命率%、致命伤害%、命中%
（2）额外造成100%的伤害 → 需要提高造成的伤害量 → 攻击力%、致命率%、致命伤害%
（3）处于恐惧，造成的伤害提升10倍 → 需要提高造成的伤害量 → 攻击力%、致命率%、致命伤害%
（4）40%的概率刷新自己技能的cd → 技能的刷新频率依赖队友，不考虑额外的属性词条
（5）20%的概率让每个目标陷入恐惧，如果友方有地属性龙，则恐惧的概率增加10% → 恐惧概率的提升依赖队友，不考虑额外的属性词条；该负面效果不受效果命中影响，不将效果命中%纳入考虑范围；技能说明中没有提到对效果命中%的需求，不考虑效果命中%
（6）每次释放主动技能都有50%的概率刷新。一次技能最多可以连续释放3次 → 技能的刷新频率依赖自身，概率无法控制，但造成的伤害量依赖属性词条 → 攻击力%、致命率%、致命伤害%
（7）队长技：不予计入考虑范围内。
-总结：玄武需要的属性词条为：攻击力%、致命率%、致命伤害%、命中%，根据上述优先级、比重分析和后端的基础比重参照，进行增减运算后可得到最终输出。

    "rationale":"攻击龙，技能含额外伤害与恐惧增伤，侧重攻击三件套与命中"
